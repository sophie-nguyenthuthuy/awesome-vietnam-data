# Đóng góp / Contributing

🇻🇳 **Tiếng Việt**

Cảm ơn bạn đã quan tâm! Cách đóng góp:

**Thêm nguồn dữ liệu vào danh sách (README):** mỗi mục một dòng, định dạng `[Tên](url) — mô tả ngắn (có gì trong đó, cách truy cập)`. Nguồn phải truy cập hợp pháp; không nhận dump cào từ các trang có ToS cấm. Vui lòng cập nhật cả `README.md` (EN) và `README.vi.md` (VI) nếu có thể.

**Thêm/sửa dữ liệu trong `data/`:** CSV, UTF-8 (NFC), phân cách dấu phẩy, dấu chấm thập phân, tên cột `snake_case` không dấu. Bắt buộc ghi rõ nguồn và năm số liệu trong `data/README.md`. Số liệu phải kiểm chứng được từ nguồn công khai.

**Báo link hỏng hoặc số liệu sai:** mở Issue kèm link/nguồn đúng.

---

🇬🇧 **English**

Thanks for contributing! How to:

**Add a source to the list (README):** one line per entry, format `[Name](url) — short description (what's in it, access method)`. Sources must be legally accessible; no scraped dumps of ToS-protected sites. Please update both `README.md` (EN) and `README.vi.md` (VI) if you can.

**Add/fix data in `data/`:** CSV, UTF-8 (NFC), comma-separated, dot decimals, `snake_case` ASCII column names. Always document the source and reference year in `data/README.md`. Figures must be verifiable from public sources.

**Report a dead link or wrong figure:** open an Issue with the correct link/source.
